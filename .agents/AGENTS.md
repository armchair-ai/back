# Reglas del Proyecto

Este archivo contiene reglas y directrices globales que todos los agentes de IA deben seguir de manera obligatoria en cada turno para este espacio de trabajo.

## Reglas de Sintaxis y Formato

- **Estilo de Código:** Sigue estrictamente las convenciones estándar de formato según el lenguaje de programación del proyecto (por ejemplo, PEP 8 para Python, PSR-12 para PHP, etc.).
- **Comentarios:** Mantén todos los comentarios y docstrings existentes que no estén relacionados con las modificaciones directas de código.
- **Tipado Estricto:** Asegúrate de declarar tipos de datos en firmas de funciones, métodos y variables siempre que el lenguaje lo soporte (ej. type hints en Python 3.14).
